# Dependensi pihak ketiga

Hak atas kode aplikasi asal tetap mengikuti pemilik dan ketentuan aslinya. Daftar ini bukan pemberian lisensi baru atas seluruh aplikasi.

| Komponen | Penggunaan | Sumber/lisensi |
| --- | --- | --- |
| Vercel Blob SDK 2.8.2 | Koneksi Blob Private dari server | https://github.com/vercel/storage — Apache-2.0 |
| Nodemailer 10.2.1 | SMTP OTP | https://github.com/nodemailer/nodemailer — MIT-0 |
| Chart.js 4.4.9 | Grafik browser | https://github.com/chartjs/Chart.js — MIT |
| DOMPurify | Sanitasi template HTML | https://github.com/cure53/DOMPurify — Apache-2.0 atau MPL-2.0 |
| SheetJS CE 0.20.3 | Ekspor Excel | https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js — Apache-2.0 |
| Tailwind CSS 3.4.17 | Pembuatan CSS | https://github.com/tailwindlabs/tailwindcss — MIT |
| Playwright | Pengujian lokal | https://github.com/microsoft/playwright — Apache-2.0 |

Versi paket npm yang terpasang tercatat tepat di `package-lock.json`. Lisensi aset browser disertakan dalam `LICENSES/`; kode vendor juga mempertahankan keterangan hak cipta asalnya. Dependensi npm membawa berkas lisensi masing-masing saat diinstal.
